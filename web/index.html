      The baselines are three hand-written strategies: random, fill the hopper and ignore the HUB, and a greedy planner that waits for its own HUB windows. The third one is what the AI has to beat.

      Analytic model vs full engine

      (μ+λ) evolution on the strategy weights. Fitness is win rate plus point margin plus the BONUS rungs that can still move — npm run rp measures which those are, and on this build only TRAVERSAL is: ENERGIZED and SUPERCHARGED are reached in 100% of MATCHes on both arms, so their terms add the same 1.7 to every candidate and select between nobody. Selection is paired: every candidate, the incumbent included, is scored on the same MATCHes each generation, so "improved" never means "measured on easier seeds". The result line prints the selection noise it measured — the spread between candidates on identical MATCHes — and a gain smaller than about twice it is the seed set, not the weights. The browser budget is small, so treat a run here as exploratory; scripts/train.mjs is the same search offline and refuses to return weights that do not beat the shipped set on seed families it never trained on.
